# hkex-reader
HKEX Reader

## Command Line

Working Dir: /HKEXReader/

dotnet run [STOCKCODE] [OUTPUT FOLDER] [TARGET DATE]

```sh

dotnet run #####,##### ../output yyyy-MM-dd

dotnet run 00001,00002,00003,00005,00008,00017 ../output 2026-06-30

```

## Retrieve Stock List

```sh

dotnet run STOCKCODE ../output

```
